# Marketing-ROI-Budget-Reallocation-Attribution-Regression-
End-to-end marketing analytics pipeline: ETL, last-touch attribution, Marketing Mix Modeling (OLS/Ridge regression), and data-driven budget reallocation for an e-commerce company.

This  project builds a full marketing analytics stack for a multi-channel e-commerce business. It covers raw data cleaning and ETL (Python), last-touch attribution modeling, KPI analytics across Search, Paid Social, Email, Referral, and Organic channels, and a Marketing Mix Model using OLS and Ridge regression with log-spend transformations and lag features. The final output is a data-backed budget reallocation plan with base/best/worst-case revenue impact estimates, supported by a dashboard and a decision memo for leadership.
